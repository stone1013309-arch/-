# 健身日記

每天記錄訓練的手機網頁 App（Next.js，可加到主畫面當 PWA）。

- **預設腿 → 拉 → 推循環**：依上一次的訓練自動判斷「今天該練什麼」，新紀錄會預選建議部位
- **沒練就是休息**：當天沒記錄，隔天起自動算成休息日（今天還沒過完不算）；也可以手動按「休息」
- **今天做了什麼**：勾選部位＋寫下動作、重量、組數
- **今日照片**：拍照或從相簿選，自動壓縮後存在手機上
- **AI 判斷**：把照片＋備註交給 Claude，判斷今天練的是腿／拉／推，並給一句建議，可一鍵套用
- **備份到手機**：把紀錄＋照片打包成一個 `.json` 檔，存到手機的「檔案」或「下載」，換手機時用「從備份還原」

## 開發

```bash
pnpm install
cp .env.example .env.local   # 填入 ANTHROPIC_API_KEY（只有 AI 判斷需要）
pnpm dev
```

部署到 Vercel 時，在專案的 Environment Variables 加上 `ANTHROPIC_API_KEY`。

## 資料存在哪？

| 資料 | 位置 | 說明 |
|---|---|---|
| 訓練部位、備註、AI 判斷結果 | 瀏覽器 `localStorage`（key：`fitness-workout-log-v2`） | 純文字，很小 |
| 照片 | 瀏覽器 `IndexedDB`（資料庫 `fitness-photos`） | 壓縮成長邊 1280px 的 JPEG |

資料**只存在手機上**，不會上傳到任何伺服器（按 AI 判斷時，照片只會送給 Claude 判斷一次，不會被保存）。

為了不讓資料不見：

1. App 開啟時會請瀏覽器開啟「持久保存」（`navigator.storage.persist()`），手機空間不足時系統不會自動清掉
2. 建議把網頁「加到主畫面」當 App 用（iOS 對加到主畫面的網頁保存得最穩）
3. 定期按「備份到手機」，備份檔會存進手機內存的「檔案」/「下載」資料夾；清除瀏覽器資料或換手機時，用「從備份還原」救回來

如果想要資料「直接寫在手機的檔案裡」、完全不靠瀏覽器，就需要包成原生 App（例如用 Capacitor 打包，
再用它的 Filesystem 存到 Documents 資料夾）。
