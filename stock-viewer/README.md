# 📈 看盤小程式

用瀏覽器看台股和美股，綜合**技術面、籌碼面、基本面**自動判斷多空，並用回測檢查判斷準不準，還能掃描台灣 50 找股票。

## 怎麼開

1. 先安裝 [Python 3.10 以上版本](https://www.python.org/downloads/)（Windows 安裝時記得勾選「Add Python to PATH」）
2. Windows：雙擊 `run.bat`
   Mac / Linux：在終端機執行 `./run.sh`
3. 瀏覽器會自動打開 http://localhost:8501

## 四個分頁

| 分頁 | 內容 |
|---|---|
| 📋 自選股總覽 | 每檔股票的報價、多空指數、綜合判斷 |
| 📊 個股分析 | 綜合判斷＋每項指標的理由、支撐壓力、K 線／成交量／KD／RSI／MACD 圖 |
| 🧪 回測 | 過去 5 年每天的判斷，之後 5 天、20 天實際上漲的機率和平均報酬；歷史評分走勢圖 |
| 🔍 選股掃描與排行 | 掃描台灣 50 找出偏多股票；今日漲幅、成交量暴增、KD 低檔黃金交叉排行 |

## 判斷規則

每項指標給 −2～+2 分，乘上權重後換算成**多空指數（−100～+100）**：
+50 以上強烈偏多、+20 以上偏多、−20～+20 盤整中性、−20 以下偏空、−50 以下強烈偏空。

| 類別 | 指標 | 偏多（+） | 偏空（−） |
|---|---|---|---|
| 技術面 | 均線趨勢 | 多頭排列、站上月線季線、MA5 黃金交叉 MA20 | 空頭排列、跌破月線季線、死亡交叉 |
| | 成交量 | 價漲量增（≥ 20 日均量 1.5 倍） | 價跌量增 |
| | KD | 黃金交叉（低檔加重）、K 在 D 之上 | 死亡交叉（高檔加重）、K 在 D 之下 |
| | RSI | 50～70、<20 嚴重超賣 | 30～50、≥80 嚴重超買 |
| | MACD | 黃金交叉、零軸上紅柱放大 | 死亡交叉、零軸下綠柱放大 |
| | 週線趨勢 | 週均線多頭、週 MACD 紅柱 | 週均線空頭、週 MACD 綠柱 |
| 籌碼面（台股） | 法人籌碼 | 近 5 日外資、投信同步買超 | 同步賣超 |
| | 融資融券 | 股價漲但融資減少；券資比 ≥ 30%（軋空） | 股價跌但融資增加（散戶接刀）；融資暴增（追高） |
| 基本面 | 基本面 | 本益比低、殖利率 ≥ 5%、營收年增 ≥ 20% | 本益比高、虧損、營收衰退 |

另外兩條規則：

- **大盤濾網**：大盤（台股看加權指數、美股看 S&P 500）偏空時，個股的偏多分數打五折；大盤偏多時偏空分數打五折。
- **週線確認**：週線沒有同方向時，「強烈偏多／偏空」降一級。

左側「⚖️ 指標權重」可以調整每項指標的比重（0 = 不納入），回測分頁會即時反映，方便找出最準的組合。

## 資料來源

- 股價：Yahoo Finance（約延遲 15–20 分鐘）
- 台股法人、融資融券、本益比、殖利率、月營收、EPS：[FinMind](https://finmindtrade.com)。不用註冊也能用，但每小時次數有限；自選股很多時建議免費註冊取得 Token，貼到左側「🔑 FinMind Token」，或設定環境變數 `FINMIND_TOKEN`。
- 台灣 50 成分股清單在 `tw50.py`，成分股調整時可自行修改。

## 代號怎麼打

| 市場 | 範例 |
|---|---|
| 台股上市／上櫃 | `2330`、`0050`（自動判斷上市 .TW 或上櫃 .TWO） |
| 美股 | `AAPL`、`NVDA`、`TSLA` |
| 其他 | Yahoo Finance 代號，例如 `^TWII`（加權指數）、`^GSPC`（S&P 500） |

> ⚠️ 判斷只根據過去的資料計算，不代表未來走勢，也不構成投資建議。
