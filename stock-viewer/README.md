# 📈 看盤小程式

用瀏覽器看台股和美股：自選股報價、K 線、均線、KD、RSI、MACD，並綜合所有指標自動判斷多空情勢。

## 怎麼開

1. 先安裝 [Python 3.10 以上版本](https://www.python.org/downloads/)（Windows 安裝時記得勾選「Add Python to PATH」）
2. Windows：雙擊 `run.bat`
   Mac / Linux：在終端機執行 `./run.sh`
3. 瀏覽器會自動打開 http://localhost:8501

## 功能

- **自選股總覽**：收盤價、漲跌、漲跌幅、成交量（紅漲綠跌）。在左側新增或移除股票，清單會存在 `watchlist.json`。
- **個股走勢**：K 線＋MA5／MA20／MA60、成交量、KD、RSI、MACD 一次全部顯示。
- **綜合判斷**：五項指標各給 -2～+2 分，加總後判斷「強烈偏多／偏多／盤整中性／偏空／強烈偏空」，並列出每項指標的理由和近 20 日支撐、壓力。自選股總覽也會顯示每檔股票的判斷結果。

## 判斷規則

| 指標 | 偏多（+） | 偏空（−） |
|---|---|---|
| 均線趨勢 | 多頭排列（價 > MA5 > MA20 > MA60）、站上月線季線、MA5 黃金交叉 MA20 | 空頭排列、跌破月線季線、MA5 死亡交叉 MA20 |
| 成交量 | 價漲量增（≥ 20 日均量 1.5 倍） | 價跌量增 |
| KD | 黃金交叉（低檔 K<30 加重）、K 在 D 之上 | 死亡交叉（高檔 K>70 加重）、K 在 D 之下 |
| RSI | 50～70 多方優勢、<20 嚴重超賣有反彈機會 | 30～50 空方優勢、≥80 嚴重超買 |
| MACD | 黃金交叉（零軸下加重）、零軸上紅柱放大 | 死亡交叉（零軸上加重）、零軸下綠柱放大 |

總分 ≥ +5 強烈偏多、+2～+4 偏多、−1～+1 盤整中性、−4～−2 偏空、≤ −5 強烈偏空。

> ⚠️ 判斷只根據過去的價格和成交量計算，不代表未來走勢，也不構成投資建議。
- 期間可選 1 個月到 5 年。

## 代號怎麼打

| 市場 | 範例 |
|---|---|
| 台股上市／上櫃 | `2330`、`0050`（程式會自動判斷是上市 .TW 還是上櫃 .TWO） |
| 美股 | `AAPL`、`NVDA`、`TSLA` |
| 其他 | 直接輸入 Yahoo Finance 代號，例如 `^TWII`（加權指數）、`^GSPC`（S&P 500） |

資料來源是 Yahoo Finance，報價大約延遲 15–20 分鐘，僅供參考。
